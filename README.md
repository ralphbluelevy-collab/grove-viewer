# The Grove — web viewer

Online copy of the lightweight V23 viewer. Open `index.html` via the published link.

- Choose a location from **Go to**.
- **Orbit**: drag to rotate; scroll/pinch to zoom; right-drag/two-finger drag to pan.
- **Walk**: drag to look; W A S D or arrow keys move; Q/E descend/ascend; Shift moves faster.
- **Photo renders** opens the full-detail images.

This copy uses a compressed version of the 3D model (36 MB instead of 114 MB) so it loads faster online. The offline original lives in `../grove-viewer` and is unchanged. Credits: see `ASSET-CREDITS.md`.
